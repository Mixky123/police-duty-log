## เทคโนโลยีที่ใช้

- **ภาษา:** Python 3
- **เว็บเฟรมเวิร์ก:** Flask (routing, session, template engine Jinja2)
- **ฐานข้อมูล:** SQLite (ตอนพัฒนาในเครื่อง) และ PostgreSQL (ตอนใช้งานออนไลน์) — ใช้ซอร์สโค้ดชุดเดียวกัน
- **ส่วนติดต่อผู้ใช้:** HTML5 + CSS3 (ออกแบบเอง รองรับการแสดงผลบนมือถือ)
- **เว็บเซิร์ฟเวอร์ตอนใช้งานจริง:** gunicorn
- **แพลตฟอร์มสำหรับ deploy:** Render

## การติดตั้งและรันในเครื่อง

ต้องมี **Python 3.8 ขึ้นไป** ติดตั้งในเครื่องก่อน จากนั้นทำตามขั้นตอน

**1) เปิด Terminal / PowerShell แล้วเข้าไปที่โฟลเดอร์โปรเจกต์**
```powershell
cd PoliceDutyLog
```

**2) ติดตั้งไลบรารีที่จำเป็น**
```powershell
pip install -r requirements.txt
```

**3) (ไม่บังคับ) เติมข้อมูลตัวอย่างเพื่อใช้สาธิต**
```powershell
python seed_data.py
```
คำสั่งนี้จะสร้างเจ้าหน้าที่ 6 นาย ตารางเวร 6 รายการ และเหตุการณ์ 8 รายการ

**4) รันเว็บแอป**
```powershell
python app.py
```

**5) เปิดเบราว์เซอร์ไปที่**
```
http://127.0.0.1:5000
```

> หมายเหตุ: ถ้าไม่ได้รัน `seed_data.py` ระบบจะยังสร้างฐานข้อมูลเปล่าและบัญชีผู้ดูแลเริ่มต้นให้อัตโนมัติเมื่อเปิดแอปครั้งแรก

## บัญชีผู้ใช้เริ่มต้น

ระบบสร้างบัญชีผู้ดูแลให้อัตโนมัติเมื่อเริ่มใช้งานครั้งแรก

| ชื่อผู้ใช้ | รหัสผ่าน |
|-----------|----------|
| `admin` | `admin123` |

ผู้ใช้ใหม่สามารถกดสมัครบัญชีเองได้ที่หน้า "สมัครสมาชิก" (จะได้สิทธิ์ระดับ officer)

> เพื่อความปลอดภัย ควรเปลี่ยนรหัสผ่านบัญชี admin ก่อนนำไปใช้งานจริง

## คู่มือการใช้งานทีละหน้า

### 1. เข้าสู่ระบบ
เปิดเว็บครั้งแรกจะพบหน้าเข้าสู่ระบบ กรอกชื่อผู้ใช้และรหัสผ่าน (เริ่มต้นใช้ `admin` / `admin123`)
หากยังไม่มีบัญชี กดลิงก์ "สมัครสมาชิก" เพื่อสร้างบัญชีใหม่ ระบบจะตรวจสอบรหัสผ่านยืนยันให้ตรงกันก่อนบันทึก

### 2. แดชบอร์ด
หลังเข้าสู่ระบบจะเข้าหน้าแดชบอร์ดทันที แสดงตัวเลขสรุป 4 ช่อง ได้แก่
จำนวนเจ้าหน้าที่ จำนวนเวรทั้งหมด จำนวนเหตุการณ์ทั้งหมด และจำนวนเหตุที่ยังไม่ปิด
ด้านล่างมีกราฟแท่งสรุปจำนวนเหตุการณ์แยกตามประเภท ทำให้เห็นภาพรวมสถานการณ์ได้ในหน้าจอเดียว

### 3. จัดการเจ้าหน้าที่
- กรอกแบบฟอร์มด้านบน (ยศ ชื่อ-สกุล เลขประจำตัว เบอร์โทร สังกัด) แล้วกด "เพิ่มเจ้าหน้าที่"
- รายชื่อทั้งหมดแสดงในตารางด้านล่าง แต่ละแถวมีปุ่ม **แก้ไข** และ **ลบ**
- เลขประจำตัว (Badge No.) ห้ามซ้ำ ระบบจะแจ้งเตือนหากกรอกซ้ำ

### 4. จัดตารางเวร
- เลือกเจ้าหน้าที่จากรายการ ระบุวันที่ ผลัด และสถานที่ปฏิบัติงาน แล้วกดบันทึก
- แต่ละรายการเวรปรับสถานะได้: **รอเข้าเวร → กำลังปฏิบัติ → เสร็จสิ้น**
- ลบรายการเวรที่ไม่ต้องการได้

### 5. บันทึกเหตุประจำวัน
- บันทึกเหตุการณ์โดยระบุ เวลา ประเภทเหตุ ระดับความรุนแรง (ต่ำ / ปานกลาง / สูง / วิกฤต) สถานที่ และรายละเอียด
- เลือกเจ้าหน้าที่ผู้รับผิดชอบได้ (หรือเว้นว่างไว้)
- ปรับสถานะคดีได้ระหว่าง **เปิดอยู่ / กำลังดำเนินการ / ปิดแล้ว**

### 6. ออกจากระบบ
กดปุ่ม "ออกจากระบบ" ที่มุมขวาบนเพื่อล้าง session และกลับสู่หน้าเข้าสู่ระบบ

## การนำขึ้นใช้งานออนไลน์ (Deploy บน Render)

โปรเจกต์นี้พร้อม deploy ขึ้น [Render](https://render.com) แบบอัตโนมัติด้วยไฟล์ `render.yaml`

**ขั้นตอน**
1. นำโค้ดทั้งหมดขึ้น GitHub repository
2. สมัคร/เข้าสู่ระบบ Render แล้วเลือก **New → Blueprint**
3. เชื่อมกับ GitHub repo ของโปรเจกต์ Render จะอ่าน `render.yaml` แล้วสร้างให้อัตโนมัติทั้ง
   - เว็บเซอร์วิส (Flask + gunicorn)
   - ฐานข้อมูล PostgreSQL
4. รอจน build เสร็จ จะได้ URL สำหรับเข้าใช้งานเว็บ

**การเลือกฐานข้อมูลอัตโนมัติ**
ระบบตรวจสอบ environment variable ชื่อ `DATABASE_URL`
- ถ้า **มี** (บน Render) → ใช้ PostgreSQL
- ถ้า **ไม่มี** (รันในเครื่อง) → ใช้ SQLite

จึงใช้ซอร์สโค้ดชุดเดียวกันได้ทั้งตอนพัฒนาและตอนใช้งานจริง โดยไม่ต้องแก้โค้ด

## คำถามที่พบบ่อย

**ลืมรหัสผ่าน admin หรืออยากล้างข้อมูลทั้งหมด?**
ลบไฟล์ `police_duty.db` (รวมถึง `police_duty.db-wal` และ `police_duty.db-shm` ถ้ามี)
แล้วรันแอปใหม่ ระบบจะสร้างฐานข้อมูลและบัญชี admin เริ่มต้นให้ใหม่

**เพิ่มข้อมูลตัวอย่างซ้ำได้ไหม?**
`seed_data.py` เพิ่มข้อมูลต่อท้ายทุกครั้งที่รัน หากต้องการเริ่มใหม่ให้ลบไฟล์ฐานข้อมูลก่อน
(เลขประจำตัวเจ้าหน้าที่ที่ซ้ำจะถูกข้าม เพราะตั้งให้ห้ามซ้ำ)

**รันแล้วพอร์ต 5000 ชนกับโปรแกรมอื่น?**
ตั้งค่าพอร์ตอื่นได้ผ่าน environment variable เช่น
```powershell
$env:PORT=8000
python app.py
```
